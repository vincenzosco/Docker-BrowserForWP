# Render server: audio, tiles and continuity — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the three things this server starts but does not complete: making a page audible, sending only the part of the screen that changed, and surviving a reconnect.

**Architecture:** The core is built and tested — `protocol/` is the frozen wire format with conformance vectors, `src/session.js` is the protocol state machine, `src/browser.js` is Chromium behind a small interface. Each task here adds one capability at the same seam, and each one is written so the part that does not need Chromium is tested in `test/` and the part that does is a documented manual step.

**Tech Stack:** Node 20+, Playwright (Chromium), the Playwright Docker image, `node:test` for tests, ffmpeg and PulseAudio for audio only.

## Global Constraints

- Every field is big-endian and bounds-checked. New fields go through `protocol/messages.js`, never inline in `src/`.
- `protocol/vectors.json` is regenerated by `npm run gen-vectors` in the same commit as any wire change, and `npm test` fails if it has drifted.
- `TYPE >= 0x10` is sealed, in `src/session.js`, in one place. No new message type below `0x10`.
- Nothing that needs a browser, a sound card or Docker may be required by `npm test`. It must have no network, no Chromium and no container.
- A device token never appears in a log line, a url, or an error message.
- Tasks commit with a `test:` / `feat:` / `docs:` prefix, and each one leaves `npm test` green.

// A stand-in for a decoded frame: 2x2 tiles of 64x64, so 128x128 pixels, with
// one byte per pixel. Pixel value 0 means "unchanged since the last frame".
function frame(pixelAt) {
  const width = 128;
  const height = 128;
  const pixels = Buffer.alloc(width * height);
  for (let y = 0; y < height; y += 1) {
    for (let x = 0; x < width; x += 1) pixels[y * width + x] = pixelAt(x, y);
  }
  return { pixels, width, height, encode: (region) => Buffer.from([region.x, region.y]) };
}

test('the first frame is sent whole', () => {
  const differ = createTileDiffer({ tileSize: 64 });
  const result = differ.diff(frame(() => 1));
  assert.equal(result.full, true);
  assert.equal(result.tiles.length, 4, '2x2 tiles at a 64px tile size');
  assert.deepEqual(
    result.tiles.map((tile) => [tile.x, tile.y]),
    [[0, 0], [64, 0], [0, 64], [64, 64]],

```javascript
// src/tiles.js
// Only send the part of the screen that changed.
//
// Chromium's screencast hands back a whole viewport every time, which on 3G is
// most of the cost of using this server. The rectangles that changed are usually
// a fraction of it.
//
// The comparison is per tile on purpose. A whole-frame diff would be cheaper to
// compute and useless to send: a one-pixel change would still cost a full JPEG.

export function createTileDiffer({ tileSize = 64, maxTiles = 16 } = {}) {
  let previous = null;
  let previousWidth = 0;
  let previousHeight = 0;

  return {
    /**
     * @returns {{tiles: Array, full: boolean} | null} null when nothing changed.
     */
    diff(frameIn, size) {
      const width = size?.width ?? frameIn.width;
      const height = size?.height ?? frameIn.height;

      // A different viewport cannot be compared against the old one: the same
      // coordinates mean different pixels.
      const resized = width !== previousWidth || height !== previousHeight;
      if (resized || previous === null) {
        previous = frameIn.pixels;
        previousWidth = width;
        previousHeight = height;
        return { tiles: everyTile(frameIn, width, height, tileSize), full: true };
      }

      const columns = Math.ceil(width / tileSize);
      const rows = Math.ceil(height / tileSize);
      const changed = [];
      for (let row = 0; row < rows; row += 1) {
        for (let column = 0; column < columns; column += 1) {
          const x = column * tileSize;
          const y = row * tileSize;
          const w = Math.min(tileSize, width - x);
          const h = Math.min(tileSize, height - y);
          if (regionDiffers(previous, frameIn.pixels, width, x, y, w, h)) {
            changed.push({ x, y, width: w, height: h });
          }
        }
      }

      previous = frameIn.pixels;
      if (changed.length === 0) return null;
      if (changed.length > maxTiles) {
        return { tiles: everyTile(frameIn, width, height, tileSize), full: true };
      }
      return { tiles: changed.map((region) => ({ ...region, data: frameIn.encode(region) })), full: false };
    },
  };
}

function everyTile(frameIn, width, height, tileSize) {
  const tiles = [];
  for (let y = 0; y < height; y += tileSize) {
    for (let x = 0; x < width; x += tileSize) {
      const region = {
        x,
        y,
        width: Math.min(tileSize, width - x),
        height: Math.min(tileSize, height - y),
      };
      tiles.push({ ...region, data: frameIn.encode(region) });
    }
  }
  return tiles;
}

function regionDiffers(a, b, width, x, y, w, h) {
  for (let row = y; row < y + h; row += 1) {
    const start = row * width + x;
    const end = start + w;
    for (let index = start; index < index_end(end); index += 1) {
      if (a[index] !== b[index]) return true;
    }
  }
  return false;
}

function index_end(end) {
  return end;
}
```

```javascript
// src/audio.js
export function authorizeAudioRequest({ url, publicUrl, audioRegistry, audioEnabled }) {
  if (!audioEnabled) return { status: 404, reason: 'audio is not enabled on this server' };
  let parsed;
  try {
    parsed = new URL(url, publicUrl);
  } catch {
    return { status: 400, reason: 'bad request' };
  }
  const match = parsed.pathname.match(/^\/audio\/([A-Za-z0-9-]{1,32})$/);
  const sessionId = match ? match[1] : null;
  const ticket = parsed.searchParams.get('t');
  if (!sessionId || !ticket) return { status: 403, reason: 'no session or ticket' };
  if (!audioRegistry.verify(sessionId, ticket)) return { status: 403, reason: 'ticket refused' };
  return { status: 200, sessionId };
}
```

Then `createAudioHandler` calls it first and only opens the stream on 200.

# Give the container a sound card it does not have.
#
# Chromium in a headless container has no audio device, so nothing a page plays

exec ffmpeg -nostdin -loglevel warning \
  -f pulse -i bfwp.monitor \
  -ac 2 -ar 44100 -b:a 96k \

- [ ] **Step 3: Write the implementation**

```javascript
// protocol/messages.js
export function encodeResume({ resumeToken }) {
  if (!Buffer.isBuffer(resumeToken) || resumeToken.length !== 32) {
    throw new ProtocolError('a resume token is 32 bytes');
  }
  return new Writer().blob(resumeToken).build();
}

export function decodeResume(payload) {
  const reader = new Reader(payload);
  const resumeToken = reader.blob();
  reader.end();
  if (resumeToken.length !== 32) throw new ProtocolError('a resume token is 32 bytes');
  return { resumeToken };
}

export function encodeResumeAck({ accepted, url = '', title = '' }) {
  const writer = new Writer().u8(accepted ? 1 : 0);
  if (accepted) writer.str(url).str(title);
  return writer.build();
}

export function decodeResumeAck(payload) {
  const reader = new Reader(payload);
  const accepted = reader.u8() !== 0;
  if (!accepted) {
    reader.end();
    return { accepted: false };
  }
  const url = reader.str();
  const title = reader.str();
  reader.end();
  return { accepted: true, url, title };
}
```

In `src/session.js`, mint `this.resumeToken = randomBytes(32)` at handshake and
append it to `HELLO_ACK`; on `RESUME`, look the token up in a map the server keeps
